# 霍尔效应教学仿真 2.3.0 · 快速上手

## 先看演示，再亲手操作

点击顶部“观看演示”。每一步先说明操作，再点“下一步”执行；六根导线分别高亮、逐根连接。演示继续展示归零、换向、通电、调节旋钮、等待稳定和记录读数。可连续播放、暂停或重播。

“返回实验”会还原学生原来的线路、参数和未完成读数。演示数据单独保存，不计入学生数据。

## 学生操作

1. 左键点击测试仪端子，再点击实验箱对应端子，连接一根线。依次完成 IS、V、IM 三路正负端的六根外线。也可用右侧端子图操作。接错后从列表移除重接；Esc 取消起点。
2. 点击“检查”查看回路状态。三路必须隔离，不能短接或跨接；两路电流设定必须为零。
3. 在“测试仪”视角点击面板红色 POWER 键，接通输出。左右拖动 IS/IM 旋钮调流，滚轮微调；控制页也可输入精确数值。红色 IS/IM 选择钮切换电流表显示。
4. 在“采样”页选择 VH-IS 或 VH-IM，等待读数稳定后记录。每组需 (+,+)、(+,−)、(−,−)、(−,+) 四个方向，顺序不限。
5. 换向先归零关闭输出，再点击实验箱上的刀闸。电流刀闸依次切换正向、断开、反向；电压刀闸依次切换 VH、断开、Vσ。恢复同一组的相同电流幅值后再次记录。
6. 完整四方向组自动保存。改变扫描电流，重复测量；在“数据”页按批次查看表格与拟合。删除可撤销最近一次操作。

相机操作：右键旋转、中键平移、滚轮缩放，Home 返回全景。鼠标位于电流旋钮上时，滚轮用于调流。

## 保存与恢复

数据页显示 CSV 路径；可打开记录目录或另存到其他可写目录。保存失败时不要直接强制结束进程，可重试、另存或保留恢复后退出。

启动发现未保存数据会提示恢复。点过“稍后处理”后，可到“器材”页点击“恢复未保存数据”。损坏的恢复文件会被跳过并保留；恢复并保存后可继续处理其他会话。

未完成的四方向组不保存到磁盘；退出会提示。软件不自动重新载入此前已经成功导出的历史 CSV。

## 运行要求与常见问题

- Windows 10/11 64 位，支持 DirectX 11 的显卡与驱动；建议 4 GB 内存、500 MB 空间、1280×800 或更大屏幕。可离线使用，无需安装 Unity。
- 默认“节能”画质，30 FPS；“器材”页可切换“标准”60 FPS。如果卡顿，切回节能并关闭其他占用显卡的软件。
- 便携版必须完整解压，不能只拷贝 Hall-Teaching.exe。安装版可单独拷贝 Setup.exe 到另一台支持的电脑再安装。
- 打不开或黑屏时，核对是否为 64 位 Windows、文件是否解压完整、显卡驱动是否支持 DirectX 11。不能在 macOS、Linux 或任意配置上保证运行。
- 重置装置会清空接线和未完成组，已完成的数据保留。演示中重置会返回学生实验。

这是未经实机标定的教学模型。样品 X/Y 仅演示机构运动，不改变计算磁场；POWER 是新增仿真操作键，不代表实物相同布局。来源、许可和用途边界见“使用与来源说明.md”。
