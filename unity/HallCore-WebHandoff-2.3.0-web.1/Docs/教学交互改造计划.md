# 教学交互改造与交付计划

目标版本：2.3.0。默认学生自行完成接线、检查、通电、调流、刀闸换向和采样；演示只用于教学，使用独立数据。

1. 保存 2.2.1 Git 基线；保留现有发布包。
2. 将学生界面的标准接线/自动实验改为观看演示和操作提示。演示每一步讲解后等待下一步，可连续播放、暂停、重播和返回学生实验；逐根高亮端子并连接。
3. 绑定三维 IS/IM 旋钮（拖动、滚轮微调）、电源和电流表选择按钮；刀闸直接点击切换，保留辅助面板以便小屏和精确输入。学生模式给出随状态变化的实验提示。
4. 演示保持独立模型与存储，返回时恢复学生线路、采样与数据；操作锁、归零和稳定等待继续生效。
5. 修复恢复候选选择、损坏文件跳过、稍后重新打开与删除最后一行的快照持久化；加入针对性检查。
6. 提供节能/标准画质、帧率上限与 Windows x64 离线发布。明确最低要求，不声称任意电脑皆可运行。样品位置仍为机构示意，明确提示，不引入未经依据的空间磁场公式。
7. 集中版本管理，补图标依赖和安装器构建脚本；修正不存在的文档链接。历史原报告找不到时保留缺失事实，不伪造证据。
8. 执行 Unity 构建、基础回归、自动流程、新教学流程与恢复边界检查，检查截图，核验安装包载荷与发布文件；生成 ZIP 和单文件安装 EXE。

验收：默认不显示一键完成入口；学生可逐根接线且接错不会被自动修正；演示能停在每一步；三维旋钮和刀闸改变实际模型参数；演示退出还原学生会话；损坏快照不阻挡有效恢复；低配置模式可切换；所有发布文件有校验清单。
