# Web 交接输入：实验步骤、参数与测量数据

核对日期：2026-09-19。基线：当前源码 2.3.0，Unity 2022.3.62f3c1，内置渲染管线。本文是迁移阶段的输入/参数快照；当前 WebBridge、网页事件和 WebGL 产物以同目录 `Docs/Web交接-通信协议-v1.md`、源码及仓库根目录 `public/sim/Build` 为准，文末的“尚未实现”条目保留作历史差距记录，不代表当前平台没有对应网页功能。

本文整理现有实现，供 Web 端制定正式通信规范；不是已实现的 WebBridge 协议。步骤以项目当前 TH-H 样品（a）接线与教学流程为依据，尚未逐页核验完整教材。模型未经实机标定。

## 1. 实验操作步骤

1. **认识仪器与样品。** 识别测试仪、工作电流 IS 与励磁电流 IM 控件、电压表、电磁铁、样品架及三个刀闸。样品为 N 型硅；D/E 为工作电流端，A/A′ 为霍尔电压端，A′/C′ 为纵向电压端。
2. **断电接线。** 测试仪 IS+、IS−、V+、V−、IM+、IM− 分别连接实验箱同名公共端，共六根外线。内部固定接线不由学生重接。可保留错误外线，供检查与纠错。
3. **检查回路。** 核对三路隔离、无电源短路、无测量输入短路、回路完整。IS、IM 刀闸选正向，中间刀闸选 VH。实际方向以回路判定为准，反向外线也会改变方向。
4. **电流归零后开机。** 将 IS、IM 设定均归零，点击 POWER 接通输出。当前没有独立的电压表调零、零点校准或真实预热流程，不能将电流归零记为“仪表已调零”。
5. **设置电流并等待稳定。** 调整 IS、IM，读取实际电流、电压和模型磁场。有效采样要求实际 IS ≥ 0.15 mA、IM ≥ 0.05 A，电压在 ±200 mV 内，且满足稳定性条件。
6. **记录第一个方向。** 点击“记录当前方向”，取得该方向的原始电压。该值包含模型中的副效应和噪声，不是已经合成的霍尔电压。
7. **完成另外三个方向。** 每次先归零、关闭输出，再切换 IS/IM 刀闸；重新通电，恢复本组相同电流设定并等待稳定，再记录。不得带电改线或换向。四种方向记录顺序不限；重复记录同一方向会覆盖该方向槽位。
8. **合成一组霍尔电压。** 四个方向齐全后自动生成完整数据行，当前桌面版自动保存 CSV。组内必须保持 IS/IM 设定、磁场幅值和电压接线方向一致；改变条件时应清除未完成组后重新采样。
9. **完成两类扫描。** VH-IS：固定 IM、改变 IS；VH-IM：固定 IS、改变 IM。每个设定点重复四方向测量。不同扫描类型、固定电流条件或主动新建批次应分开分析。现有演示各生成六组，不等于教材强制规定点数。
10. **结束实验。** 电流归零并关闭输出，交付原始方向记录和完整组数据。Web 端完成表格展示、拟合、霍尔系数计算和报告。当前没有网页结束接口或结果回传。

### 四方向编号：必须明确顺序

当前源码方向顺序为 **(IS 方向, IM/B 方向)**，不是 (B, IS)。在当前模型中 B 跟随 IM 方向。

| 槽位 | IS 方向 | B 方向 | 当前简写 | 按 (B, IS) 表示 |
|---|---:|---:|---|---|
| V1 | +1 | +1 | ++ | ++ |
| V2 | +1 | −1 | +− | −+ |
| V3 | −1 | −1 | −− | −− |
| V4 | −1 | +1 | −+ | +− |

当前合成公式：`VH_mV = (V1 - V2 + V3 - V4) / 4`。
当前分析值：`normalizedVH_mV = VH_mV * voltageDirection`，后者用于抵消电压表外接线反向的影响。

接口建议分别传 `isDirection`、`imDirection`、`voltageDirection`，不要只传一个未定义顺序的 `direction` 字符串。

## 2. 当前学生可操作参数

下面的英文名是接口候选名称，不是已存在的网页字段。

| 参数 | 候选字段 | 范围/取值 | 单位 | 初始值 | 说明 |
|---|---|---|---|---|---|
| 工作电流设定 | isSetpoint_mA | 0–10 | mA | 0 | 旋钮拖动/滚轮每格 0.05；也有输入框和滑条 |
| 励磁电流设定 | imSetpoint_A | 0–1 | A | 0 | 旋钮拖动/滚轮每格 0.005；也有输入框和滑条 |
| IS 刀闸位置 | isSwitch | −1、0、+1 | 无 | +1 | 反接、断开、正接；实际极性还取决于外线 |
| IM 刀闸位置 | imSwitch | −1、0、+1 | 无 | +1 | 反接、断开、正接；实际极性还取决于外线 |
| 测量刀闸位置 | measurementSwitch | −1、0、+1 | 无 | +1 | 分别为 Vσ、断开、VH；不是单纯电压正负切换 |
| 输出电源 | powered | false / true | 无 | false | 接线有效且电流设定归零才允许开机 |
| 样品 X 位置 | stageX | −1–+1 | 归一化 | 0 | 仅机构演示，不影响磁场/读数，不应声明为实物毫米行程 |
| 样品 Y 位置 | stageY | −1–+1 | 归一化 | 0 | 同上 |
| 扫描类型 | sweepType | VH-IS / VH-IM | 无 | VH-IS | 有未完成四方向组时禁止切换 |
| 学生接线 | cables | 12 个外部端子间的连接 | 无 | 空 | 最多 12 根；标准流程使用六根 |

电流底层目前会将超范围输入截到合法范围，不能据此声称已有“越界输入异常上报”。原始请求值应在截断前由新接口检查并记录。

辅助操作还包括电流表 IS/IM 显示切换、视角调整、画质切换、演示播放控制；它们不改变样品物理参数。

### 当前固定的样品与模型参数

| 参数 | 当前值 | 学生能否修改 |
|---|---|---|
| 样品材料 | N 型硅单晶（参考样品） | 否 |
| 厚度 d | 0.5 mm | 否 |
| 宽度 | 4.0 mm | 否 |
| 纵向电极间距 L | 3.0 mm，不是整个样品长度 | 否 |
| 载流子浓度 | 2.30 × 10²² m⁻³ | 否；教学假设 |
| 迁移率 | 0.50 m²/(V·s) | 否；教学假设 |
| 磁感应强度 B | 根据有符号 IM 和磁响应模型计算 | 不能直接设定；随 IM 间接变化 |
| 电压表量程 | ±200 mV | 否 |

若交接要求案例可选材料、厚度和参数范围，必须先把相关常量改为可配置模型并补校验；当前不存在可以直接交付的材料列表或厚度可调范围。

## 3. 当前数据清单

### 实时状态：已有内存值，但没有网页上报

| 源码字段 | 含义 | 单位/取值 |
|---|---|---|
| ActualIsMilliamps | 实际工作电流幅值 | mA；方向另传 |
| ActualImAmps | 实际励磁电流幅值 | A；方向另传 |
| MagneticFieldTesla | 模型磁感应强度，带符号 | T |
| CoilVoltageVolts | 模型线圈端电压，带符号 | V |
| LiveReading.totalMillivolts | 仪表原始总电压读数 | mV |
| CircuitReport.IsDirection / ImDirection | 实际回路方向 | −1、0、+1 |
| CircuitReport.VoltageDirection | 电压接线方向 | −1、0、+1 |
| CircuitReport.HallMode | 当前是否 VH 模式 | bool |
| SamplingStable | 是否满足采样稳定条件 | bool |
| MeasurementCount | 本组已记录方向数 | 0–4 |

LiveReading 还包含理想霍尔电压、不等位电势、Ettinghausen、Nernst、Righi–Leduc、噪声及纵向电压等模型分量。它们是仿真内部值，不是额外实测通道；如用于教师诊断，应明确标为模型分量。

### 完整四方向组：现有 CSV schema 4，共 24 列

| CSV 列 | 源码字段 | 含义与单位 |
|---|---|---|
| 类型 | label | VH-IS / VH-IM |
| IS(mA) | primaryCurrent | 本组工作电流设定幅值，mA |
| IM(A) | secondaryCurrent | 本组励磁电流设定幅值，A |
| V1–V4(mV)，4 列 | v1–v4 | 四方向原始总电压，mV |
| VH(mV) | vh | 对称合成霍尔电压，mV |
| B1–B4(T)，4 列 | b1–b4 | 每个方向采样时的有符号模型磁场，T |
| 批次 | seriesId | 分析批次 ID |
| 电压方向 | voltageDirection | +1 / −1 |
| VH归一(mV) | NormalizedHall | vh × voltageDirection，mV |
| IS1–IS4(mA)，4 列 | is1–is4 | 四次采样实际 IS 幅值，mA |
| IM1–IM4(A)，4 列 | im1–im4 | 四次采样实际 IM 幅值，A |
| 记录ID | id | 唯一数据行 ID |

注意：无论扫描类型是什么，primaryCurrent 始终指 IS、secondaryCurrent 始终指 IM，不随横坐标改变含义。

当前操作日志另存时间与操作描述；会话元数据另存 sessionId、创建 UTC 时间、样品尺寸、模型参数和量程。**完整数据行目前没有逐次采样时间戳、学生步骤号或操作得分字段。** 未完成四方向组当前不作为有效数据持久化。

### Web 交接建议新增字段（尚未实现）

- 公共信息：schemaVersion、eventId、sessionId、caseId、stepId、timestamp（建议统一 UTC ISO 8601）、elapsedMs、isDemo。
- 单方向测量事件：groupId、slot、设定/实际 IS 与 IM、三个方向、B_T、rawVoltage_mV、stable、valid。不能把单方向原始电压直接命名为合成 VH。
- 完整组事件：上表全部测量信息、四次采样时间、合成 VH 和归一 VH；与单方向事件明确区分。
- 操作/异常：操作类型、请求参数、实际结果、成功/失败、稳定异常代码、原因详情、发生时状态。
- 完成事件：完整数据集、未完成组状态、操作与异常记录、耗时及可供 Web 评分的客观证据；不由 Unity 判分。

霍尔系数建议由 Web 根据明确的方向约定计算 `RH = VH * d / (IS * B)`，单位 m³/C。计算前将 mV、mA、mm 转换为 V、A、m，并拒绝零分母/无效组；使用与合成极性一致的基准方向，不能把四次有符号 B 直接平均为零。当前没有学生测量结果的 RH 输出字段。

## 4. 已有异常检测与待补埋点

以下代码名仅为正式接口规范的候选，现有代码主要返回布尔值和中文说明，未实现这些事件代码。

| 候选异常码 | 条件 | 当前状态 |
|---|---|---|
| CIRCUIT_SOURCE_SHORT | 电流源短路 | 已检测，禁止通电 |
| CIRCUIT_CROSS_CONNECTED | IS/IM/测量回路跨接 | 已检测，禁止通电 |
| CIRCUIT_METER_SHORT | 测量输入短路 | 已检测 |
| CIRCUIT_INCOMPLETE | 漏接或开关断开 | 已检测 |
| POWER_ON_NONZERO_CURRENT | 电流设定未归零即开机 | 已拦截；不等于未校准零点 |
| LIVE_WIRING_CHANGE / LIVE_SWITCH_CHANGE | 带电改线/换向 | 已拦截 |
| READING_UNSTABLE | 电流/磁场尚未稳定 | 已拒绝采样 |
| VOLTAGE_OVER_RANGE | 超出 ±200 mV | 显示 OL，拒绝采样 |
| CURRENT_TOO_LOW | 实际 IS < 0.15 mA 或 IM < 0.05 A | 已拒绝采样 |
| GROUP_CONDITION_CHANGED | 组内电流/磁场幅值或电压方向不一致 | 已拒绝采样 |
| PARAMETER_OUT_OF_RANGE | 请求值超范围 | 底层截断；需补请求检查和日志 |
| ZERO_CALIBRATION_REQUIRED | 未完成电压表调零 | 未实现调零状态与此检测 |

稳定性标准：实际 IS 距设定 ≤0.025 mA、IM ≤0.004 A；磁场距模型目标 ≤0.001 T 且同号；变化率 ≤0.005 T/s；连续保持至少 0.25 s，超过 0.1 s 的单帧不计作连续稳定。以上为软件采样规则，不是实机精度指标。

## 5. 与目标交接标准的差距

- 实验主要闭环和对称采样已实现；电压表调零、可选材料/厚度尚未实现。
- 现有重置清除接线、设定及未完成组，但**保留完整数据与当前会话**；网页“重新开始”若意味着新会话，需要另定语义，不能直接等同于现有 ResetControls。
- 现有学生流程没有统一可跳转步骤状态机；演示 LessonStep 也不能直接当学生 stepId。GotoStep 不应绕过接线、断电和稳定性约束。
- WebBridge、网页事件、结束回传和结构化异常埋点均待实现；GotoStep 参数在需求表与示例中分别是 int/string，正式规范需统一。
- 当前 Unity 中已经有表格和拟合；目标版本将分析职责交给 Web，需要后续迁移，本次不删除已有功能。
- 当前为内置管线，WebGL 不必先改 URP；尚无通过构建与浏览器联调验收的 WebGL 产物。
