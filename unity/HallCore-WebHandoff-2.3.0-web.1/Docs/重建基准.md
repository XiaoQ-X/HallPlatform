1. [厂商产品全景](https://www.tianhuang.cn/products/prodPreInfo.aspx?p_id=1005)：整体轮廓、颜色、部件组成与位置的首要参照。

3. [江汉大学配套文档](https://phylab.jhun.edu.cn/59/8b/c3388a88459/page.htm)：固定线/外接线等关系的交叉核对。
4. [高校实验箱照片](https://www.hip.edu.cn/wldst/info/1108/1016.htm)：结构辅助。网页未给型号，不认定为同一批次。

| 对象 | 已有证据 | 当前实现中的近似 |
| --- | --- | --- |

| 实验箱 | 开盖、金属包边、前排三个开关 | 500×540 mm 平面是比例估计；扣件与把手细节近似 |
| 电磁铁 | 右后部、红色单线圈、浅色骨架、深色铁轭 | 磁路和气隙近似，不用于磁场计算；没有确认极靴尺寸 |
| 样品架 | 左侧探杆和二维调节 | 机构内部近似；滑条为归一化行程，不显示未经核实的毫米刻度 |
| 样品 | 硅片参数与电极示意 | 托片/封装占位；3 mm 是电极间距而非整个样品长度，画面外形长度不可据此反推 |
| 三个开关 | IS 换向、VH/Vσ 选择、IM 换向 | 第 2 阶段已加入触点导通；公共端外侧插座和机械细节仍为可操作近似；中位不认定为实物定位档 |
| 接线 | 厂家预接线与三对外接端子 | 第 2 阶段已按说明书建立图模型；实际导线的走线路径、长度、叠插造型并无尺寸依据 |

所有设备位于普通台面；测试仪放左、实验箱放右是本项目的可操作布局选择，不声称为实机唯一正确摆法。

## 后续顺序

1. 核对装置大体结构和可观察性，再细化已知部件；对缺少来源的部分保留近似标签。
2. 从选定 TH-H 接线图建立端子模型，分离厂家固定连接和三对学生外接连接。
3. 把物理求解与三维外观分离；已知样品参数、演示假设和实机标定数据单独管理。
4. 核对恒流源、仪表量程、四方向测量、记录及曲线。保留旧代码中经重新测试的功能，不能把旧演示常量直接当实机规格。

## 当前不作的承诺

不声称毫米级复刻；不声称已还原不可见的设备内部；不输出伪实测电压；不把未经标定的 B–IM 曲线当作 TH-H 的实机特性。

## 第 2 阶段修正（2026-09-18）

- 删除原先六条外接线的显隐演示，外接线改由端子连接数据生成。
- 外接线从原先误取的前排触点改到开关公共端；永久跨接线与样品/线圈线按同一图模型逐边绘制。
- 统一采用说明书样品（a），不混入样品（b）的电极接法；中间开关为 VH / Vσ 电极选择。
- 开关绕横向轴翻转，不再绕竖直轴转 180°；绝缘握柄采用对称形状，避免下接时穿入底座。
- 补充端子极性标签、触点夹、公共端桥片、五根样品线束和 C 悬空标识。样品架移动时固定端与移动端之间的软线更新。
- 调整探杆长度和样品归位坐标，使硅片默认落在当前近似磁极的平面范围内，且高度位于上下极面之间；加入三轴几何检查。这是本模型装配一致性修正，不是新确认的实物尺寸。
- 保留既有机箱/实验箱/磁铁/样品架比例，未因新增细节而提高其证据等级。封装和引线微观走向仍是说明性表达。
