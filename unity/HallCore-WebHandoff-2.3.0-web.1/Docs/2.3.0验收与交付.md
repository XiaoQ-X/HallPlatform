## 已完成

- 默认学生实验，不显示标准接线或自动完成按钮。学生逐根连接三维端子或辅助面板，错误连接保留并由检查反馈。

- 修复删空表后的恢复快照；跳过损坏的最新恢复文件，并提供重新打开恢复入口。
- 默认节能画质 30 FPS、关闭阴影，可切换标准 60 FPS；使用 Direct3D 11。
- 建立 Git 基线并提交改造；恢复备份中的重建基准。不存在的旧报告不再被 README 引用。
- 集中版本常量，补齐图标依赖初始化、构建、测试、ZIP、安装 EXE 生成脚本；附快速使用指南。

## 明确保留的边界

支持目标是 Windows 10/11 x64 与支持 DirectX 11 的显卡/驱动；建议至少 4 GB 内存、500 MB 空间和 1280×800 屏幕。这是发布目标而非所有硬件实测认证，不能保证任意电脑/系统都运行。安装器没有代码签名。

物理模型未实机标定；X/Y 位置只演示机构，不改变计算磁场，界面与指南已明确说明。未找回的历史整改报告不重写为虚假的历史证据。此次没有把整套自定义测试迁移到 Unity Test Framework 或部署远程 CI，也没有进行大型代码架构重写。
